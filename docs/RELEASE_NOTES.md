# The Working Page

## Presentation release — 3 November 2026

Noetherwake now presents learning as a working sheet with a ruled evidence margin. The redesign covers every top-level and learning screen: Today, placement, lessons, practice, Atlas, Library, the projectile laboratory, routes, Field notes, completion and Preferences. Navigation vocabulary is unified across desktop, tablet and phone.

The release adds locally hosted Newsreader, Instrument Sans and IBM Plex Mono; warm-paper and blueprint themes; a wake wordmark and install icons; shape-coded evidence; numeric answer gaps; prerequisite traces; keyboard derivation reveals; and a chronological evidence ledger. Practice drafts survive in-tab navigation. JSON import has an atomic validation preview, and deletion requires typed confirmation.

The pure learning engine and its policy, all 67 authored concepts, IndexedDB version 1, valid existing backups, static export, offline delivery and Vercel configuration remain compatible. No XP, telemetry, fabricated history or inactive controls were introduced. Historical marks are withheld when retained responses cannot reproduce stored knowledge.

See [DEPLOYMENT.md](DEPLOYMENT.md) for the deployed source revision and live verification.
