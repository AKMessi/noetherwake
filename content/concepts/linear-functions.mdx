## Intuition

A linear model combines a starting value with a constant rate of change. The intercept tells you where counting begins; the slope tells you how the total changes per step.

## Formalism

$$f(x)=mx+b$$

Start at b when x is zero, then add m for each unit of input. Equal input increments produce equal output increments.

[Explore slope](concept:slope). [Explore equations](concept:equations).

## Worked example

For f(x)=3x+4, find f(3).

Start with the defining relationship. Start at b when x is zero, then add m for each unit of input. Equal input increments produce equal output increments. Substitute the given values: **`3*3+4` = 13 **. Keep the unit through the calculation and check whether the sign and scale fit the situation.

## Where it breaks

A linear extrapolation may fail outside the measured range; physical rates are seldom constant forever.

A common trap is: **treating the intercept as the slope**. Read f(0) first, then compare f(1) with f(0).
