## Intuition

An equation says that two descriptions have the same value. Solving finds the value that makes the constraint true. A balance remains level when the same reversible operation is applied to both sides.

## Formalism

$$ax+b=c\quad\Rightarrow\quad x=\frac{c-b}{a}$$

Undo addition first, then undo multiplication. Substitute the candidate into the original constraint to verify it.

[Explore signed numbers](concept:signed-numbers). [Explore ratios](concept:ratios).

## Worked example

Solve 3x + 4 = 3*6 + 4.

Start with the defining relationship. Undo addition first, then undo multiplication. Substitute the candidate into the original constraint to verify it. Substitute the given values: **`6` = 6 **. Keep the unit through the calculation and check whether the sign and scale fit the situation.

## Where it breaks

Dividing by an expression that could be zero can remove solutions. Multiplying both sides by zero loses information.

A common trap is: **moving a term without an inverse operation**. Write the same subtraction explicitly on both sides before simplifying.
