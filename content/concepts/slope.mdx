## Intuition

Slope compares a vertical change with the horizontal change that produced it. A steep line changes output quickly. A position-time slope measures speed with direction.

## Formalism

$$m=\frac{\Delta y}{\Delta x}$$

For a straight line every right triangle along it is similar, so rise divided by run is constant.

[Explore coordinates](concept:coordinates). [Explore ratios](concept:ratios).

## Worked example

y rises 3 while x rises 4. Find slope.

Start with the defining relationship. For a straight line every right triangle along it is similar, so rise divided by run is constant. Substitute the given values: **`3/4` = 0.75 **. Keep the unit through the calculation and check whether the sign and scale fit the situation.

## Where it breaks

Vertical lines have no finite slope. A curved graph has different secant slopes on different intervals.

A common trap is: **reversing rise and run**. Write the units of output divided by units of input before inserting numbers.
