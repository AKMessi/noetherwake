## Intuition

A function is a rule assigning exactly one output to each allowed input. The domain is part of the rule: division, square roots and physical constraints can exclude inputs.

## Formalism

$$f:A\to B,\qquad x\mapsto f(x)$$

A machine view helps separate a symbol for an input from the value currently placed in the machine. Substitution replaces every occurrence of that input.

[Explore linear functions](concept:linear-functions). [Explore quadratics](concept:quadratics).

## Worked example

For f(x)=x^2+3, find f(4).

Start with the defining relationship. A machine view helps separate a symbol for an input from the value currently placed in the machine. Substitution replaces every occurrence of that input. Substitute the given values: **`4^2+3` = 19 **. Keep the unit through the calculation and check whether the sign and scale fit the situation.

## Where it breaks

A relation such as a whole circle can give two y values for one x and is not a single function y=f(x).

A common trap is: **assuming every expression accepts every real input**. Locate denominators and roots before evaluating; ask which inputs make them undefined.
