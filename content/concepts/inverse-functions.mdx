## Intuition

An inverse reconstructs the input from an output. It exists as a function only when different allowed inputs do not collapse onto the same output.

## Formalism

$$f^{-1}(f(x))=x$$

Swap the input and output roles, then solve the original relation for the old input. Restrict a domain if information was lost.

## Worked example

f(x)=3x+4. Find f inverse at 4+3*3.

Start with the defining relationship. Swap the input and output roles, then solve the original relation for the old input. Restrict a domain if information was lost. Substitute the given values: **`3` = 3 **. Keep the unit through the calculation and check whether the sign and scale fit the situation.

## Where it breaks

The inverse of x squared requires a chosen branch. The notation f inverse does not mean the reciprocal 1/f.

A common trap is: **confusing inverse and reciprocal**. Test whether applying your candidate after f returns the original input.
